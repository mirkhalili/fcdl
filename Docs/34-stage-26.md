# Stage 26 — modular workspace (initial migration)

The new startup workspace offers a visual directed acyclic graph: add multiple independent modules, move them, click an output then a compatible input to connect, right-click an input to disconnect, and run the selected module. The runner evaluates only its dependencies and fans an output into multiple independent branches. Port types and cycles are checked; replacing a connection is atomic. Changes invalidate cached previews. The default starter graph is editable and can be saved to `.jgw`, including embedded raster source, node settings, connections and copied project weave patterns. Importing a PDF/AI currently embeds the rendered first page, not the original vector document.

Functional modules include file loading, resize, adaptive color reduction, a project weave collection (select multiple from the bank or create on a grid), color-to-weave mapping, selvedges, float scan/optional correction, relative warp analysis, weft layout, basic simulation and experimental JC5 machine output. Selvedges and repeated weft placement after signal columns are rejected rather than silently corrupting signal hooks. Manual machine wiring and bit polarity still require independent verification. The editor can only operate on one incoming connection per input; one output can feed many modules.

**Migration is not complete.** The graph does not yet include all previous detailed capabilities: region-based color editing, color locks/palette PNG, manual float editing, detailed yarn-per-weft/3D simulation, PDF reports, or automatic migration of SAM projects to editable graphs. Existing `.sam` projects still open in the previous workspace, accessed via Open or “ابزارهای تکمیلی”; that separate workspace is not linked to graph node outputs. Continue to use it where those operations are needed. This fallback is retained to avoid silently losing project data while migration is unfinished.

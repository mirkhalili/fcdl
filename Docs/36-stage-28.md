# Stage 28 — Blender-inspired graph and weave designer

The graph uses neutral editor surfaces, a subtle grid, compact headed nodes, an orange active outline, and colored sockets/wires by data type, inspired by Blender's node editor rather than copied assets. The right library, per-module help, drag insertion and double-click editors remain. Middle-mouse drag pans the canvas; Ctrl+wheel zooms around the pointer. The graph toolbar now offers a persisted light/dark theme, shared with the legacy workspace; text, icons and common controls use corresponding theme colors. Weave banks show compact selectable image thumbnails rather than name-only rows.

A new independent **Weave Designer** node outputs one self-contained weave collection compatible with the mapping input. Its editor reuses the original bank and full grid designer (drawing, helpers, undo/redo, 3D preview, bank editing/import, composite tool). Apply stores a copy and Cancel leaves the graph unchanged. The bank node's “create new” button uses the same full designer to add another weave to that node. Saving or deleting items in the shared bank is an explicit separate action and is not rolled back by Cancel. Existing JGW files remain readable; newly created designer nodes need this version or newer.

This is not a complete transfer of all legacy tools into the graph: manual float edits, detailed yarn-per-weft/3D simulation and reports still live in the separate legacy workspace; SAM files open there without conversion. The editor's vector PDF/AI input is rasterized on import. JC5 output remains experimental; Bonas support is derived from one sample and has not been validated on a real loom.

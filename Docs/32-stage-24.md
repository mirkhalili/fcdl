# Stage 24 — sample-based Bonas JC5, indexed colors and fabric preview

The supplied `bonas.txt` was a ZIP containing `orgin1.bmp`, `col-pat.png`, `baft.bmp` and `machin.jc5`. It is the same sample already in `tests/fixtures/designscope-reference.zip` (JC5 SHA-256 `a378d4fa18d1641bbb7453ac3be8b35d4d1b1ccb0fe7f5bfa97e5392693e04c7`). Its 133-byte header identifies EAT OpenWeave Converter. The 1200×1200 single-area raster is bottom row first, least-significant bit first; bit 1 matches every red pixel in `baft.bmp` (all 1,440,000 pixels checked). The independent Bonas JC5 UI profile uses the same existing sample-based codec, `.jc5` extension and active-bit polarity, without claiming the file was produced by EAT. **One sample does not establish general Bonas controller compatibility. Verify bit polarity, hook mapping and file behavior on the intended controller before production.** Export still follows the applied machine layout and Box Motion, not the illustrative red preview.

Initial color preparation uses an adaptive weighted median-cut palette of at most 256 colors, displayed as Indexed8. If the resized, transparency-normalized image has at most 256 colors, all are retained exactly; dimensions use nearest-neighbor and alpha below 128 is normalized to white as before. Explicit later color reductions keep the existing frequency-based rule. SAM v12 accepts up to 256 palette and weave entries, while older SAM files remain loadable. Report color listings are paginated.

For the actual project map, black indicates weft over warp; white indicates warp over weft. Normal mode uses per-row applied weft yarn, soft crossing shadows and softened gaps; fiber mode adds a procedural yarn-dependent texture, and 3D uses the same polarity. This convention changes only the visual simulation, not machine bits. Simple/twill selections are alternate display-only structures. These visualizations and diameter calculations are estimates, not physical validation. Reports always recompute the **normal, actual-map** preview from fabric-only composition and applied row sequence regardless of the selected visual mode or alternate structure, and include paginated warp/weft definitions with color, material, count/unit and estimated diameter.

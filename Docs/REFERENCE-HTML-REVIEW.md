# بررسی مرجع تخصصی و نقشه توسعه ژاکارد استودیو

## دامنه و روش

مرجع ارائه‌شده `HTML.zip` در commit `607ad19` شاخه کاری موجود است (در زمان بررسی، `main` فقط README ابتدایی داشت). SHA-256 آرشیو `4a0a5d48f85713594505d2bc04fc6f7fe7c2b9cf674acdcbf9f522e0ebb4f8ce` است. همه ۵۰۱۸ فایل با خواندن محتوای ZIP و کنترل CRC فهرست و هش شدند: ۱۳۴۴ HTML، ۳۶۷۰ PNG، یک PDF چهارصفحه‌ای میان‌بر، یک CSS، یک GIF و یک JPG. پوشه‌های ۱۴۹تایی HTML با GUID شناسایی شده‌اند؛ تعداد صفحات معادل تعداد امکانات مستقل نیست، چون صفحه‌های frame، نمای برنامه، اجزای کنترل و صفحه‌های تکراری هم وجود دارند.

`reference-html-inventory.csv` مسیر، اندازه و SHA-256 **تمام فایل‌های داخل آرشیو** را برای ردیابی دارد. بازتولید: `python tools/inventory_reference.py HTML.zip Docs/reference-html-inventory.csv`. در این مرحله نمایه‌سازی و مرور ساختاری کل آرشیو و بررسی عمیق‌تر بخش‌های منتخب انجام شده است؛ به معنی خواندن انسانی تک‌تک توضیحات، تأیید همه تصاویر، کشف کامل فرمت‌های اختصاصی یا پیاده‌سازی همه امکانات نیست. متن و تصاویر مرجع، متعلق به صاحب حقوق آنهاست؛ راهنمای داخل برنامه مستقل و فارسی نوشته شده و تصاویر/متن مرجع به خروجی برنامه کپی نشده‌اند. استفاده عملیاتی و توزیع خود آرشیو تابع حقوق و مجوز دارنده آن است.

## راه توسعه و معیار پذیرش

1. **ایمنی پایه و راهنما:** نقشه دودویی معتبر، تشخیص ابعاد، مسیرهای خروجی و واحدها؛ راهنمای محلی برای هر عملکرد و پیام خطای قابل اقدام. معیار: آزمون متون و مسیرهای عملیاتی و بررسی انسان روی رابط.
2. **فلوت و کنترل کیفیت:** نمایش مختصات و چهار حالت تار/پود و رو/پشت با قطبیت صریح، آستانه قابل تنظیم، و پیش‌نمایش قبل/بعد؛ تصمیم اصلاح فقط با تأیید کاربر. آزمون: خطوط یکنواخت، مرز راپورت، کناره، سیگنال، مقایسه طرح دست‌محاسبه‌شده و حفظ داده خارج محدوده. تحلیل جدید صرفاً نخستین گام است.
3. **داده بافت و ناحیه:** مدل ماسک غیردستکاری‌کننده، تطبیق پالت با روش و فاصله معلوم، بافت مستقل چندسیستمی و امکان undo. آزمون: پروژه قدیمی، نواحی هم‌پوشان، حفظ رنگ‌های قفل و خروجی قابل تکرار.
4. **تعریف ماشین و کنترل تولید:** پروفایل نسخه‌دار و مدل صریح نقش/رزرو/نگاشت زه، تشخیص هم‌پوشانی و متادیتای تفکیک‌شده از پیکسل. آزمون فایل‌های واقعی ورودی/خروجی با شاهد از هر کنترلر؛ هیچ پشتیبانی یا قطبیتی صرفاً از نام سازنده نتیجه گرفته نشود.
5. **سازمان‌دهی و خروجی:** تاریخچه پروژه، مستندسازی تغییرات، گزارش‌های مهندسی و خروجی جدول کامل؛ آزمایش بازیابی در شرایط خطا، مهاجرت و جلوگیری از بازنویسی منبع.
6. **پیشرفته:** دابی، نوار، کنترل سرعت و تراکم و شبیه‌سازی دقیق، تنها پس از تعیین استانداردها و فراهم‌شدن نمونه معتبر و متخصص دامنه.

همه این موارد مستلزم کار بیشتر هستند. معیار نهایی سازگاری صنعتی آزمایش مستقل روی دستگاه و بررسی اپراتور است، نه شباهت رابط یا قبولی آزمون نرم‌افزاری.

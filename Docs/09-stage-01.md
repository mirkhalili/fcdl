# مرحله ۱: پوسته و پیش‌نمایش ویندوز

شناسه پیشنهادی نخستین بسته آزمایشی: `001.1.0.0-a1` بر اساس QAVNS؛ شماره انتشار ۰۰۱، نسل ۱، فهرست قابلیت ۰، تصحیحات ۰ و پیش‌انتشار آلفا. این شماره نخستین **بسته نرم‌افزاری** است؛ مستندات پیشین نسخه نرم‌افزار محسوب نشده‌اند. شناسه به معنای تأیید صنعتی یا نبود نقص نیست. به دلیل محدودیت محیط جلسه، همه مراحل روی شاخه ثابت جلسه کار می‌شوند و با commit و شناسه بسته از هم تفکیک می‌شوند.

## قابلیت‌های این مرحله

برنامه WPF ویندوز x64: رابط فارسی/انگلیسی، بازکردن یا رهاکردن BMP/TIFF، انتخاب صفحات TIFF، نمایش ابعاد، عمق پیکسل و نوع تشخیص‌داده‌شده، بزرگ‌نمایی nearest-neighbor و پیام‌های وضعیت. این مرحله فقط پیش‌نمایش است؛ تحلیل نقشه قلاب، ذخیره، تبدیل و خواندن/نوشتن JC یا EP هنوز وجود ندارند.

محدودیت پیش‌نمایش: حجم فایل تا ۱۲۸ MiB، حداکثر ۱۰۰ صفحه و هر صفحه تا ۴۰ میلیون پیکسل. این حدود به معنی تضمین امنیت یا کارایی در برابر فایل‌های خراب یا فشرده‌سازی مخرب نیستند؛ نمونه‌های ناشناس را با احتیاط و خارج از محیط تولید بررسی کنید. فایل منبع تغییر نمی‌کند. در این نسخه انتخاب هر صفحه تصویر را دوباره باز می‌کند.

## ساخت و آزمون

روی Windows x64 با .NET 10 SDK و Inno Setup 6:

```powershell
dotnet build src/JacquardStudio/JacquardStudio.csproj -c Release
dotnet run --project tests/JacquardStudio.Smoke/JacquardStudio.Smoke.csproj -c Release
dotnet publish src/JacquardStudio/JacquardStudio.csproj -c Release -r win-x64 --self-contained true -o artifacts/publish
& "${env:ProgramFiles(x86)}\Inno Setup 6\ISCC.exe" packaging/JacquardStudio.iss
```

workflow ویندوز همین مراحل را انجام می‌دهد و بسته نصب و SHA-256 را به‌صورت artifact بارگذاری می‌کند. بسته self-contained است و به نصب جداگانه runtime نیاز ندارد؛ نصب در سطح کاربر انجام می‌شود. بسته امضای دیجیتال ندارد و ممکن است Windows SmartScreen هشدار دهد. اعتبارسنجی installer، تعامل بصری، DPI و صفحه‌خوان روی دستگاه واقعی هنوز ضروری است؛ نتیجه workflow را پیش از اعلام موفقیت بررسی کنید.

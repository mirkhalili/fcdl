# تحقیق فرمت‌ها و محصولات مرتبط

تاریخ بررسی: ۲۰۲۶-۱۱-۰۶. منابع زیر از صفحات عمومی و راهنماها بررسی شده‌اند؛ ادعاهای فروشندگان درباره محصولاتشان شواهد قابلیت آن محصولات‌اند، نه مشخصات باینری یا تضمین سازگاری پروژه ما.

## مقایسه پروژه‌ها و برداشت عملی

| پروژه | آنچه می‌توان آموخت | محدودیت |
|---|---|---|
| [ArahWeave](https://www.arahne.si/products/arahweave/) | ماتریس فرمت‌ها، جزئیات پسوند، رسانه و تفاوت نسل‌ها | محصول تجاری؛ فهرست قابلیت، مشخصات باینری یا مجوز کپی نیست |
| [EAT DesignScope](https://www.designscopecompany.eu/products/jacquard-weaving) | تخصیص بافت و کنترل حاشیه و float در گردش کار | محصول تجاری؛ امکان استفاده از API یا فایل باید مستقلاً توافق شود |
| [DigiTextileMan](https://github.com/gbasak2014/DigiTextileMan) | ایده تفکیک طرح، الگو و خروجی punch | توصیف مخزن گواه پشتیبانی JC4/JC5/Bonas نیست؛ مجوز و کیفیت کد پیش از هر استفاده بررسی شود |
| [Jacquard](https://github.com/Mohammad-Diab/Jacquard) | تجربه تبدیل تصویر به شبکه، انتخاب اندازه و پیش‌نمایش | پروژه شبکه عمومی است، نه کدک صنعتی؛ مخزن مجوز Apache-2.0 ذکر می‌کند؛ رعایت شرایط مجوز قبل از استفاده |
| [WIF specification](http://www.tantradharma.com/maplehill/wif/wif1-1.txt) | واژگان و مبادله بافت | معادل فایل دستگاه یا مسیر بدون اتلاف نیست؛ مجوز سند و سازگاری پیش از پیاده‌سازی بررسی شود |

هیچ کد یا داده شخص ثالثی به پروژه وارد نشده است. مخزن حاضر هنوز مجوز پروژه انتخاب نکرده است؛ پیش از استفاده مجدد از کد، وابستگی، نمونه یا باینری، صاحب پروژه باید مجوز و شرایط توزیع را بررسی کند.

## مسائل باز تحقیق

مشخصات دقیق بایت‌ها، ترتیب بیت، packing، فشرده‌سازی، امضا، checksum، اندازه‌ها، منطقه‌ها، داده‌های توابع و متادیتا در منابع بررسی‌شده روشن نیست. هیچ الگوریتمی از نام پسوند حدس زده نمی‌شود. مسیرهای بررسی: سند رسمی یا SDK با مجوز؛ همکاری با سازنده/دارنده نرم‌افزار؛ یا تحلیل نمونه‌های مجاز با رعایت قانون و قرارداد، با آزمون مستقل. اگر هیچ مسیر معتبری فراهم نشود، پشتیبانی آن گونه مسدود می‌ماند.

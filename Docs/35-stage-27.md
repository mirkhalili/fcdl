# Stage 27 — node workspace and palette bridge (partial migration)

The library is on the right, with click or drag/drop insertion and a help button per module. Double-click a card to open its editor; completed paths show thumbnails on their cards. Changes in the simple graph editors can be canceled; Apply evaluates the path and closes on success. The existing resize and palette stages open on isolated snapshots. Applying commits dimensions or the edited palette and locks to that node; downstream modules consume the edited palette. `.jgw` saves these edits. If the upstream image changes, execution stops until the color node is reopened and applied; cancel leaves the old edits intact.

This is still a partial migration: **other modules use the graph's simplified settings dialogs, not their full legacy stage UI**. Manual float edits, detailed yarn-per-weft/3D simulation and PDF reporting remain in the separate legacy workspace and do not feed the graph. Opening SAM projects also remains in that separate workspace, without automatic conversion. The project weave editor is simplified. PDF/AI graph inputs are rasterized first pages. Bonas JC5 remains experimental, checked against only one sample; mapping and polarity require independent device verification.

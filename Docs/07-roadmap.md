# نقشه راه و تصمیم‌های توسعه

زمان‌بندی پس از تعیین دستگاه، پیچیدگی نمونه و دسترسی به منابع معتبر برآورد می‌شود؛ اعداد و پشتیبانی تجاری پیشاپیش تضمین نمی‌شوند.

| مرحله | تحویل | شرط عبور |
|---|---|---|
| ۰. کشف و تحقیق | مستندات، انتخاب اولین کنترلر، دریافت نمونه و توافق محدوده | پاسخ به موارد مسدودکننده [چک‌لیست](08-discovery-checklist.md) و تعیین مسیر قانونی فرمت |
| ۱. پایه ویندوز | solution، WPF، تم، RTL/LTR، آزمون‌های پایه، ساخت روی Windows | تأیید طراحی نمونه، ساخت تمیز و تست دسترسی پایه |
| ۲. تصویر و مدل | خواندن/نوشتن BMP/TIFF در زیرمجموعه مستند، مدل lift map، تبدیل‌های صریح و پیش‌نمایش | T01–T06، T11–T13 برای قابلیت‌های اجراشده |
| ۳. پروفایل و بررسی | مدل نسخه‌دار پروفایل، نگاشت، validation، گزارش و رابط بررسی | تست مرز قلاب و خطاهای مسدودکننده |
| ۴. اولین کدک صنعتی | تنها یک گونه و نسخه کنترلر انتخاب‌شده، خواندن و نوشتن، گزارش اتلاف | شواهد معتبر، تست طلایی مستقل و پذیرش واقعی طبق برنامه آزمون؛ در غیر این صورت مسدود |
| ۵. تکمیل مسیرهای بافت | تخصیص رنگ به بافت، float و حاشیه به تناسب نیاز | تعریف دامنه توسط متخصص نساجی و تست نمونه پارچه/ماشین |
| ۶. افزایش پوشش | JC4/JC5/JC6 و Bonas اضافی به صورت جداگانه | تکرار آزمون و پذیرش مستقل برای هر ترکیب، نه صرفاً نام خانواده |
| ۷. انتشار | بسته نصب، امضا در صورت فراهم بودن گواهی، راهنما، نسخه‌بندی و پشتیبانی | اجرای معیار انتشار و رضایت کارفرما |

ترتیب مراحل ۴ و ۵ به ماهیت تصاویر واقعی بستگی دارد. اگر داده ورودی فقط طرح رنگی باشد، قابلیت رنگ→بافت و تأیید متخصص پیش‌نیاز تحویل صنعتی است.

## تصمیم‌های باز و ریسک

| موضوع | ریسک | اقدام |
|---|---|---|
| فرمت بسته | نبود مشخصات معتبر سبب خروجی ناسازگار و خطر تولید | دریافت SDK یا مجوز، نمونه‌های کنترل‌شده، همکاری سازنده؛ در غیر این صورت عدم صدور |
| تفاوت مدل و رسانه | پسوند یکسان ولی رفتار یا رسانه متفاوت | پروفایل و پذیرش جدا برای هر پیکربندی |
| تصویر در برابر بافت | تصویر رنگی فاقد اطلاعات بافت و توابع است | دریافت نمونه مرجع و تصمیم مشترک درباره حالت ورودی و mapping |
| محرمانگی | نمونه‌های تولیدی دارای مالکیت معنوی‌اند | مجوز کتبی، نمونه مصنوعی، نگهداری خارج از Git در صورت لزوم |
| Windows و اندازه‌های بزرگ | کندی و تفاوت نسخه‌ها | نمونه عملکردی و تست روی سخت‌افزار مرجع |
| مجوزها | ناسازگاری وابستگی یا شرایط استفاده | بررسی حقوقی پیش از استفاده و تعیین مجوز پروژه |

## آماده شروع کدنویسی

- حداقل یک مدل و نسخه هدف و مسیرهای رفت/برگشت توافق شود.
- تصویر، فایل دستگاه و داده مرجع متناظر با مجوز ارائه شود.
- وضعیت داده طرح (نقشه دودویی یا تصویر رنگی)، جهت‌ها، نگاشت قلاب و اطلاعات لازم مشخص شود.
- طراحی اولیه و فناوری تأیید شود؛ کد اولیه می‌تواند پیش از حل کدک شروع شود، اما صدور صنعتی نه.
